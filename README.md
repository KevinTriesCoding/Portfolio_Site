# Kevin Moye – Portfolio

Vite + React + TypeScript + Tailwind single-page portfolio (Kevin Moye content).

## Getting started

```bash
npm install
npm run dev
```

Then open the URL Vite prints (e.g. `http://localhost:5173`).

- **Build:** `npm run build`
- **Preview build:** `npm run preview`
- **Lint:** `npm run lint`

## Project structure

- `src/` – React app (Hero, About, Work, Process, Contact, Navbar)
- `index.html` – Vite entry
- `assets/` – Images (optional; use from `public/` if you need them in the app)
